Política de privacidad

Actualizada: 21 de octubre de 2026.

Responsable y alcance

Hermes Personal es una instalación de asistente de IA para uso personal de su propietario. Contacto sobre esta instalación y sus datos: jdelyer@gmail.com. Esta política distingue la web informativa del asistente privado.

Datos de Google utilizados

Según los permisos concedidos y la tarea solicitada, el asistente puede consultar mensajes, metadatos y etiquetas de Gmail; enviar correos y modificar su organización; consultar y gestionar eventos de Calendar; leer contactos; y consultar, crear, compartir, modificar o enviar a la papelera archivos de Drive, Docs y Sheets. Los permisos concedidos no significan que se hayan realizado todas estas operaciones.

Se utilizan credenciales OAuth, incluidos tokens de acceso y renovación. La aplicación no solicita ni almacena la contraseña de Google. YouTube no está integrado actualmente.

Finalidad y tratamiento con IA

Los datos se utilizan para ejecutar las instrucciones del propietario: búsqueda, resumen, redacción y organización personal. El contexto necesario de una tarea puede transmitirse a los proveedores de modelos de IA configurados, directamente o a través de una pasarela de modelos. No debe asumirse que el tratamiento es exclusivamente local. La configuración del modelo determina qué proveedor recibe ese contexto; antes de tratar información sensible deben revisarse el proveedor, su retención y sus condiciones.

La instalación no destina los datos de Google a publicidad, venta de datos ni entrenamiento de modelos generalistas. El uso y transferencia de información recibida de las API de Google debe respetar la Política de datos de usuario de los servicios API de Google, incluidos sus requisitos de Uso Limitado.

Almacenamiento, acceso y conservación

Las credenciales OAuth se almacenan en el servidor privado, separadas de esta web y del repositorio público, con permisos de archivo restringidos. Las conversaciones, resultados guardados, notas, registros operativos y copias de seguridad pueden contener información utilizada en las tareas. No se establece aquí un borrado automático ni un plazo fijo que no esté configurado: la conservación depende de la gestión del propietario y de las políticas de los proveedores utilizados.

Solo se deben compartir datos con servicios necesarios para una tarea autorizada. La infraestructura, los proveedores de IA y Google aplican además sus propias condiciones. Esta web no publica las credenciales ni los contenidos de las cuentas conectadas.

Revocación y eliminación

Puedes retirar el permiso desde las conexiones de tu cuenta de Google. Revocar el acceso impide futuras solicitudes autorizadas por esa concesión, pero no elimina automáticamente datos ya guardados en conversaciones, notas, registros, copias de seguridad o proveedores. Para solicitar su revisión o eliminación, contacta con el responsable. El borrado de copias y de datos conservados por terceros debe gestionarse por separado según corresponda.

Esta web informativa

Estas páginas no incorporan formularios, autenticación, scripts de seguimiento, publicidad ni cookies propias. GitHub Pages aloja la web y puede tratar datos técnicos de las visitas, como la IP, conforme a la declaración de privacidad de GitHub. Visitar estas páginas no concede acceso a tu cuenta de Google.

Cambios

Esta política debe revisarse al cambiar las integraciones, los proveedores o las prácticas de tratamiento. La fecha de actualización aparece al inicio.
